Feature Summary

The Free Balcony Upgrade promotion allows B2C customers who have selected an Oceanview cabin to receive a free upgrade to a Balcony cabin when the promotion is active. The promotion only applies when the price of the Balcony matches the price of the Oceanview — i.e. when a cabin category is priced the same as the next higher macro category. Without visibility of this pricing relationship, the booking funnel website cannot determine whether the upgrade condition is met and cannot offer or auto-apply the upgrade.

This feature adds an indicator to the booking funnel search and category responses to surface whether the lowest price for a given cabin entry is equal to the price of the next macro category above it. The indicator is derived from the reservation system and must be converted to a boolean before being returned to the website. The website uses this flag to drive the auto-selection and upgrade prompt logic for the Free Balcony Upgrade feature.

Business Requirements

Format: As a [actor] I want to [action] so that [benefit]

ID Requirements Description
BR-001 As the booking funnel, I want to receive an indicator of whether the lowest price for a cabin entry matches the price of the next higher macro category so that the website can determine whether the Free Balcony Upgrade promotion applies and offer it to the customer. The indicator must be included in the price list, cabin type, cabin preference, and category responses. The value must be derived from the reservation system and converted to a boolean. If absent in the reservation system response, it must default to false.

Use Cases

UC# PreCondition Actor/s Use Case Functionality Expected Open Questions
UC-001 A valid search or pricing request is made by the booking funnel at any step of the booking journey. B2C Website (Booking Funnel), MuleSoft, DTS Retrieve booking funnel search data including same-price-as-next-macro-category indicator The website calls INT002.1 Get Price Lists, INT002.2 Get Cabin Types, INT002.3 Get Cabin Preferences, or INT002.4 Get Categories depending on the booking step. MuleSoft retrieves the data from DTS and, for each entry, reads the SamePriceAsNextMacroCategory field from the DTS response, converts it to a boolean, and maps it to the lowestPricedCategory of the relevant entry in the response (priceTypes, cabinTypes, cabinPreferences, or categories respectively). If the field is absent in the DTS response, MuleSoft defaults the value to false and returns the response without error. —
