Feature Summary

The Kids Sail Free promotion allows minor guests to travel on a cruise at no cabin fare cost when certain qualifying conditions are met. At present, the booking funnel does not receive the Kids Sail Free availability flag from the reservation system, meaning the website cannot display the promotion during the package selection step or show an accurate fare breakdown for minor guests in the price details view.

This feature adds the Kids Sail Free indicator to the responses returned by the booking funnel's search and pricing journey. Once exposed, the website will be able to display a dedicated promotional item on qualifying package cards, and to apply a labelled fare line for each minor guest in the price details breakdown when the promotion applies to the selected cabin.

The change benefits B2C customers by making the promotion clearly visible during the booking journey, and supports the website frontend in applying consistent promotional display logic — including the correct priority ordering when multiple promotions are available simultaneously.

Business Requirements

Format: As a [actor] I want to [action] so that [benefit]

ID Requirements Description
BR-001 As the booking funnel, I want to receive the Kids Sail Free availability indicator in the search and pricing responses so that the website can conditionally display the promotion to customers. The Kids Sail Free indicator must be included in the price list, cabin type, and cabin preference responses. The value must be passed through as received from the reservation system with no modification. If absent in the reservation system response, the indicator must default to false.

Use Cases

UC# PreCondition Actor/s Use Case Functionality Expected Open Questions
UC-001 A valid search or pricing request is made by the booking funnel at any step of the booking journey. B2C Website (Booking Funnel), MuleSoft, DTS Retrieve booking funnel search data including Kids Sail Free indicator The website calls INT002.1 Get Price Lists, INT002.2 Get Cabin Types, or INT002.3 Get Cabin Preferences depending on the booking step. MuleSoft retrieves the data from DTS and maps the Kids Sail Free indicator onto the lowest priced category for each entry (price type, cabin type, or cabin preference). The value is passed through as-is from DTS. If absent in the DTS response, MuleSoft defaults the value to false and returns the response without error. —
