Feature Summary

INT142 (MyMSC Booking Details) is the MuleSoft API that provides authenticated customers in the MyMSC private area with the full details of their cruise bookings, including any prepaid excursions and onboard services they have already purchased. Customers access this area post-login to review their itinerary, purchased extras, and booking-level information.

This change enriches the data returned by INT142 for prepaid items (both excursions and onboard services) with additional fields that are currently missing from the API response. For all prepaid items, a longDescription field is added. For excursions specifically, a duration field and a minimumPassengersRequired (mapped as MinPaxRequired) are added, together with a full set of activity characteristic flags sourced from the excursion provider and exposed under an ActivityMoreInfo object. These flags cover attributes such as best seller status, transport type, accessibility, included meals and drinks, guide availability, language codes, and physical difficulty, all converted from source boolean or string values to the target boolean type as required.

In addition to the enrichment work, a defect was raised related to previously purchased excursions: when an excursion no longer exists in the upstream excursions API (for example because it has been retired or seasonally removed), the "Already Purchased" card in MyMSC Booking Details displays incorrectly — the itinerary day, port name, and duration labels are empty and replaced by placeholders, because the data is not returned in the booking response and the excursion cannot be found in the excursion API. This feature must also address how the "Already Purchased" card should behave and what data should be returned for excursions that are present in the booking history but are no longer available in the excursions API. Business Requirements

Format: As a [actor] I want to [action] so that [benefit]

ID Requirements Description
BR-001 As a MyMSC customer, I want to see a detailed description of each excursion or onboard service I have already purchased so that I can review what is included in my booking. The longDescription field must be returned for all prepaid items (both excursions and onboard services) in the INT142 API response. This field is sourced from the item info returned by the relevant upstream provider API.
BR-002 As a MyMSC customer, I want to see the duration of a purchased excursion so that I can plan my time at each port of call. The duration field must be returned for prepaid excursion items in the INT142 API response. This field is sourced from the excursions API. It is not applicable to onboard services.
BR-003 As a MyMSC customer, I want to see the minimum number of passengers required for a purchased excursion so that I understand any group size constraints that apply to my booking. The minimumPassengersRequired field (mapped as MinPaxRequired) must be returned for prepaid excursion items in the INT142 API response. This field is sourced from the excursions API and is not applicable to onboard services.
BR-004 As a MyMSC customer, I want to see the activity characteristics of a purchased excursion (such as whether it is family-friendly, includes meals, involves walking, or is accessible by wheelchair) so that I can make informed decisions about attendance and preparation. A set of activity characteristic flags must be returned under an ActivityMoreInfo object for prepaid excursion items. The full list of flags is defined in the field mapping table in the Use Cases section. All flags are boolean values converted from the source fields provided by the excursions API. Guide language codes (GuideLang) are returned as an array of strings. These flags are not applicable to onboard services.

TC-001 – HAPPY PATH Authenticated customer retrieves a booking with a prepaid excursion. All new fields are returned: longDescription, duration, MinPaxRequired, and ActivityMoreInfo flags including GuideLang as an array of strings. Excursion-specific fields are absent from onboard service items in the same response. HTTP 200 returned. All mapped fields are present and correctly typed on the excursion item. ActivityMoreInfo flags are boolean. GuideLang is an array of strings. Excursion-only fields are not present on onboard service items. Booking with at least one prepaid excursion and one prepaid onboard service, where the upstream excursions API returns values for all new source fields including a non-empty guideLanguageCodes array.
TC-002 – HAPPY PATH Authenticated customer retrieves a booking with a prepaid onboard service (no excursions). longDescription is returned for the onboard service item. HTTP 200 returned. longDescription is populated on the onboard service item. Fields duration, MinPaxRequired, and ActivityMoreInfo are absent from the onboard service item. Booking with at least one prepaid onboard service and no prepaid excursions in DTS UAT.
