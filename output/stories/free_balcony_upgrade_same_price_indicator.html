BA Stories – Free Balcony Upgrade: Same Price as Next Macro Category Indicator

Splitting Rationale

All four interfaces (INT002.1, INT002.2, INT002.3, INT002.4) are existing interfaces receiving the same change: adding the samePriceAsNextMacroCategory boolean indicator to the lowestPricedCategory of each response entry. Same change, same logical feature — consolidated into one CR. No new interfaces. No ADF interfaces involved.

CR: Add Same Price as Next Macro Category Indicator to Booking Funnel Search APIs

Type: CR

Summary: Add samePriceAsNextMacroCategory indicator to booking funnel search APIs

Description:

Change Scope: Add the samePriceAsNextMacroCategory boolean indicator to the lowestPricedCategory of each entry across four existing booking funnel search interfaces: INT002.1 Get Price Lists, INT002.2 Get Cabin Types, INT002.3 Get Cabin Preferences, and INT002.4 Get Categories. The value is sourced from DtsSearchCruisesResponseB2C.Itinerary.Cruises[N].SamePriceAsNextMacroCategory and must be transformed to a boolean by MuleSoft before being included in the response.

Rationale: The booking funnel website requires this indicator to determine whether the Free Balcony Upgrade promotion applies to a given cabin entry — specifically, whether the lowest price for that entry matches the price of the next higher macro category. Without this flag, the website cannot apply the auto-selection and upgrade prompt logic.

Acceptance Criteria (BDD):

Scenario 1: SamePriceAsNextMacroCategory is true
Given a valid request is made to INT002.1, INT002.2, INT002.3, or INT002.4 and DTS returns SamePriceAsNextMacroCategory as true for one or more entries
When MuleSoft processes the DTS response
Then the samePriceAsNextMacroCategory indicator is included in the lowestPricedCategory of the relevant entries with a boolean value of true

Scenario 2: SamePriceAsNextMacroCategory is false
Given a valid request is made to INT002.1, INT002.2, INT002.3, or INT002.4 and DTS returns SamePriceAsNextMacroCategory as false for all entries
When MuleSoft processes the DTS response
Then the samePriceAsNextMacroCategory indicator is included in the lowestPricedCategory of each entry with a boolean value of false
